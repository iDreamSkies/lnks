Install in a minute

Works on cPanel, ISPmanager, Plesk, DirectAdmin and any host with PHP 8.0+.

  1. Download

    Get the latest release ZIP and unpack it.

  2. Upload over FTP

    Copy the files into your domain or subdomain folder (with the hidden .htaccess).

  3. Open the site

    The installer checks PHP and permissions and asks for an admin login and password.

  4. Shorten

    Paste a link, get a short one. The admin panel is at /admin.php.
